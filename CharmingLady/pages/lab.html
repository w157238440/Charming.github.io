实验台 · 动效与交互

动效不是装饰，是注意力的分配方式。

这一页把整站用到的动效拆开，一项一项摆出来。每一项都标明触发条件、实现方式和降级策略—— 如果一段动画说不出它想让人看什么，它就不该出现在这里。

零依赖 · 无构建 · 支持 reduced-motion · 离屏即停

可以动手的 8 项

鼠标移到对应区域即可触发；触屏设备会自动关掉磁吸与倾斜（因为没有 hover 这一态）。

按钮 / 磁吸CSS 过渡 + pointermove

主按钮（带磁吸） 次级按钮

实现「磁吸」是按钮跟随光标做最大 4px 的位移，用 CSS 变量写入， 不做 transform 动画重排；离开后归零。

数字滚动IntersectionObserver + rAF

128 次

说明进入视口后从 0 缓动到目标值，缓动曲线 easeOutExpo，只跑一次。

降级数字写在 HTML 里，JS 不生效时直接显示最终值，不会出现空白。

卡片倾斜pointermove + transform

把鼠标放到这张卡上

最大倾角 6°，超过就像玩具；只改 transform，不改布局，所以不会带动周围元素抖动。

限制仅在 (hover: hover) and (pointer: fine) 的设备启用；触屏与减少动效偏好下完全关闭。

标题逐字入场DOM 拆分 + IO

先看结论，再看过程

可访问性拆出来的每个字都是 aria-hidden，原文写进 aria-label，读屏不会逐字念。

SVG 描边绘制stroke-dashoffset

实现用 getTotalLength() 量出路径长度写入 CSS 变量，进入视口后把 dashoffset 归零， 视觉上就是从一头画到另一头。

Canvas 波形Canvas 2D + rAF

动画开关（暂停后停在当前帧，不是清空画布）

省电离开视口或被切到后台标签页时停止绘制；减少动效偏好下只画一帧静态曲线。

光标读数pointermove + 节流

视口 X—相对本区块的百分比
视口 Y—相对本区块的百分比
区块内—0–100 的相对坐标
帧率—滚动的 rAF 计数，仅作参考

为什么留这个调动画时最想知道的就是「光标到哪了、这一帧多久」，把它摆出来比反复截图快。

颜色令牌CSS 自定义属性

--ink
--paper
--accent
--jade

规则全站只用这几个变量取值；深色主题只替换变量值，不新增选择器分支。 点右上角主题按钮可以现场对比。

这些动效的边界

加动效的成本不在写，而在「以后谁来维护、在坏设备上会怎样」。

只做一次

入场动画只在第一次进入视口时播放，滚回去不会重播。重复播放会让页面显得不安分， 而且每次都要重算位置，长页面上会明显掉帧。

只改合成属性

位移、缩放、透明度优先用 transform 与 opacity，避免动画过程中反复触发布局与重绘。 进度条用 scaleX，不用 width——后者每帧都要重新排布。

一定留退路

prefers-reduced-motion: reduce 时全部起始隐藏被取消、动画关闭、噪点与光斑隐藏， 内容照样完整可读；JS 完全失效时，页面仍是静态可用的长文档。

想看实现细节，直接看源码。

整站没有打包、没有压缩、没有混淆，打开开发者工具就能读到和源码一样的注释。 如果你要的正是「以后自己能改」，这种结构比任何框架都省心。
