三块能力不是并列的技能点，而是一条链：界面怎么用，决定接口怎么设计。

01 / FRONTEND

前端：把设计做成能维护的代码

组件拆得开、状态说得清、样式不打架。性能不是上线后再优化，而是从结构上就留好余地。

  • Vue 3 / React 组件化与状态管理，按业务复杂度选型
  • TypeScript 类型收口，改需求时先被编译器提醒
  • Vite 构建拆分，首屏只加载首屏需要的
  • 设计还原：栅格、断点、字号层级一次对齐

02 / BACKEND

后端：让接口扛得住，也让别人读得懂

接口是给未来的同事看的文档。字段命名、错误码、分页与幂等，在写第一个接口时就要定下来。

  • Node.js / NestJS 分层结构与参数校验
  • Java / Spring Boot 事务边界与并发控制
  • MySQL / Redis 索引、缓存与一致性
  • 鉴权、限流、日志与告警一套接上

03 / MINIAPP

小程序：短路径，少一步就多一成转化

小程序不是「缩小版网页」。分包、授权、支付回调，每一处都直接影响能不能过审、能不能付款。

  • 原生 / uni-app / Taro 按发布节奏选方案
  • 登录态、手机号、微信支付与退款链路
  • 分包加载、骨架屏、下拉刷新与分享卡片
  • 类目、隐私协议、内容安全接口合规

怎么合作

四步，每步都有交付物

不给「先做一版看看」这种无法验收的承诺，每一步结束你都能看到东西。

01

需求澄清 · 1–3 天

把「想要高级一点」翻译成可验收的条目：谁用、多久用一次、什么算完成。输出一份需求清单，双方确认后才动手。

交付物：需求清单 + 范围确认
02

方案与拆解 · 3–5 天

先定页面结构、数据模型与接口清单，再出可点的原型。原型阶段改一次，比开发阶段改十次便宜。

交付物：原型 + 接口草案 + 排期
03

开发与联调 · 2–6 周

小步提交，每周一个能跑起来的版本。你随时能在测试环境里点到最新进度，不用等到最后一天。

交付物：可访问的测试环境 + 每周进度
04

上线与交接 · 3–7 天

部署、监控、备份策略一起交付，附操作手册与录屏。上线后 30 天内的问题免费处理。

交付物：线上环境 + 文档 + 录屏 + 30 天维护
